In this post I go over 10 different Python packages that help you create Command line tools. I've done this to scratch that "shiny new object" ich that most developers have :)

The goal was for me to get to know the landscape of tools for this types of apps that we have out there for the Python ecosystem.

I'll use this also as my summary page to highligh the main differences between these tools

Libraries to Compare
[argparse]: Standard library, great for simple tools but may feel verbose for more complex ones.
[click]: Easy-to-use, decorator-based syntax; supports nested commands and rich user interaction.
[Typer]: Built on click, focuses on type annotations and modern Python features, ideal for auto-documentation.
[docopt]: Parses commands from a usage string, making it concise but less flexible for complex tasks.
[python-fire]: Automatically generates CLIs from Python code, great for prototyping but less customizable.
